The site you're reading right now is a project too.

## How it's built

- **[Hugo](https://gohugo.io/)** turns Markdown files into static HTML in milliseconds. No database, no server code.
- A **hand-made theme** (`themes/nerd`) with a terminal accent: a shell-prompt logo, `ls`-style post lists and code blocks with a copy button, but with readable body text and friendly navigation.
- **Light and dark** themes that follow your system setting (press `t` to switch), plus a **search** box (press `/`).
- My profile, education and skills live in a single data file, `data/profile.yaml`, which feeds both the home page and the [About](/about/) page.
- **Netlify** builds and deploys every push to `main` within seconds, with the Hugo version pinned in `netlify.toml`.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `/` | search |
| `t` | toggle light/dark |
| `g` then `h` / `p` / `r` / `a` | go to home / posts / projects / about |

## History

It started in 2022 on an off-the-shelf theme. In 2026 I replaced it with this custom one and added the project pages you're browsing now.
